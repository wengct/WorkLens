# 小貓互動驗證

在 repository 根目錄執行 `node --test tests/browser/encouragement-cat.test.mjs`。
使用 Node.js 內建測試工具，不需安裝 npm 套件；注入虛擬時鐘驗證等待、換位、聚焦、閱讀、背景暫停、減少動態效果及清理。

句庫測試：`dotnet test tests/WorkLens.Tests/WorkLens.Tests.csproj --filter FullyQualifiedName~EncouragementQuoteServiceTests`。

視覺與整合檢查須以隔離資料目錄啟動 WorkLens：

- 桌面、900px、650px、320px 與短視窗：小貓入口可按，泡泡留在視窗內，按鈕可換行。
- 小貓與泡泡必須在 content-container 的可見範圍內；四個方向都可探頭，上方為倒掛、下方為向上探頭。候選位置避開操作區，換位優先換方向。
- 泡泡尾巴指向小貓，頂部探頭向下展開、底部探頭向上展開；較短的內容區可捲動，不能越過側欄或內容區留白。
- 點擊、換句、Escape、鍵盤焦點返回、切換路由仍保留閱讀內容。
- 初次等待 5 秒；未開啟時 30～60 秒躲藏，5～10 秒後換位置；聚焦與閱讀時不移動。
- 開關對話框、展開條件面板、捲動及背景分頁：不遮住可操作區域，無安全位置時等待重試。
- 「本次先休息」後重新整理仍隱藏；新開分頁恢復。
- 系統啟用減少動態效果時，入口固定且無閃動或滑動。
- 出場偷看兩次，等待動作不連續重複；滑鼠靠近或鍵盤聚焦立即中止偷看／張望。點擊後笑眼揮爪一次，動畫完成後靜止閱讀，關閉及背景暫停清除表演狀態。
